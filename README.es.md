## ¦ Perfil README plantillas - elegir uno, hacer que sea suyo

Su perfil README (`username/username` repo) es su tarjeta de negocios GitHub. Estas plantillas son patrones de prueba de batalla — copiar la estructura, rellenar su contenido.

## 📁 La colección

### 🟢 Minimal — "menos es más"

```markdown
### Hi, I'm Name 👋
Building [project](link) — one-line pitch.
📍 City · 🌐 site.dev · 📫 me@mail.com
```

### 🧑 💻 Engineer — "stats forward"

```markdown
## Name — @handle
![Stats](https://github-readme-stats.vercel.app/api?username=YOU&show_icons=true)
![Langs](https://github-readme-stats.vercel.app/api/top-langs/?username=YOU&layout=compact)
```

## ♥ Pro tips

- Mantenlo bajo ~30 líneas - nadie se desplaza
- Un fuerte enlace de proyecto > cinco débiles
- Pin tus mejores 6 repos debajo - son parte de la tarjeta

## 🎯 Plantillas por persona

### The OSS Maintainer
Héroe mínimo, repos grabados hacen la charla. Tarjeta Stats + lista "actualmente manteniendo". Firmas: credibilidad, actividad.

### The Job Hunter
Matriz de habilidades arriba, proyectos destacados con demostraciones en vivo, resumen fácil de reclutar. Firmas: alquilables, corrientes.

### The Builder
Lo que estoy construyendo ahora / lo que se envía. Energía de cambio. Firmas: impulso.

### The Community Hub
Enlaces fuera, curación, lista de recursos (como el escaparate de este perfil). Firmas: valor de red.

## 🚫 Anti-patterns

- **Wall of badges**: Los logotipos tecnológicos √°15 leen como ruido, no profundidad. Curate a tu pila real.
A menos que sea tu marca, salta.
- Autogenerado "sobre mí"** que lista las tecnologías que tocaste una vez.
- **Los contadores rotos**: si una placa 404s, indica el abandono.
